# AI Engineering Platform Principles

1. Reliability over autonomy.
2. Verification over model confidence.
3. Explicit graphs over hidden agent loops.
4. Small specialized agents over giant agents.
5. Context quality is an engineering problem.
6. Models are replaceable behind a provider-neutral gateway.
7. Jira, Confluence and GitHub remain authoritative systems of record.
8. Execution state must be durable and recoverable.
9. Security is capability- and least-privilege-based.
10. Meaningful autonomous actions must be observable.
11. Evaluate the harness as well as the model.
12. Prefer incremental architecture and avoid unjustified infrastructure.
13. Dogfood the platform when it becomes sufficiently reliable.
14. Documentation is part of the product.
15. Human engineering accountability remains important.
