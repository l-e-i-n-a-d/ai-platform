# Contributing

Before significant changes, read:

1. CLAUDE.md
2. ARCHITECTURE.md
3. PRINCIPLES.md
4. ROADMAP.md
5. relevant ADRs

For architectural changes:

1. describe the problem
2. identify affected components
3. consider alternatives
4. record the decision when significant
5. update architecture documentation
6. implement incrementally
7. add tests
8. update implementation status

Prefer small, independently testable changes.

Do not introduce speculative infrastructure or bypass platform security/policy boundaries.
